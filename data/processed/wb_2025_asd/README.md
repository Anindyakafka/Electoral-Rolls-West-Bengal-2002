# WB 2025 ASD processed data

`removed_electors_clean.csv.gz` is generated by:

```powershell
python code/scripts/wb_2025_asd/build_analysis_dataset.py
```

Grain: one row per extracted elector. Primary key: `record_id`, constructed from the
validated `(document_id, serial_number)` key.

The transformation preserves all 5,819,543 interim rows, converts validated numeric
fields, standardizes multilingual categories, retains their source-language values,
normalizes names and EPIC identifiers, attaches missing-name source conditions, and flags
the source-reported age above 120. It performs no imputation, exclusion, translation of
names, winsorization, or deduplication.

`cleaning_qa.json` records row counts, category frequencies, unmapped values, missing-name
status counts, output size, and acceptance gates. Generated data and QA files are ignored
by Git; the dictionary and mappings live in `data/metadata/wb_2025_asd/`.

Run `validate_analysis_dataset.py` for an independent full-file pass over schema, keys,
numeric fields, EPIC completeness, category domains, name statuses, age flags, and gzip
integrity. Its result is written to `validation.json`.
